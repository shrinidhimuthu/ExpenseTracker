# Personal Expense & Daily Budget Tracker (₹)

An enterprise-grade Personal Expense & Daily Budget Tracker built with Java 17, Spring Boot, Spring Data JPA, SQLite, Jakarta Servlets, and a Tailwind CSS frontend.

## Features
- **Real-Time Budget Summary:** Tracks total spent, remaining budget, days left in the month, and safe daily allowance in Indian Rupees (₹).
- **Expense Management:** Add, view, and delete expenses categorized by food, utilities, transport, and more.
- **Enterprise Architecture:** Layered Spring Boot structure (Controller, Service, Repository, Model) combined with custom legacy Jakarta Servlets.

## Tech Stack
- **Backend:** Java 17, Spring Boot Web & Data JPA, embedded Apache Tomcat, Jakarta Servlets
- **Database:** SQLite (`expenses.db`)
- **Frontend:** Tailwind CSS, HTML5, Vanilla JavaScript
